## The roast

> My agent apologizes in twelve languages and fixes the bug in none of them.

## How it works

`main.ts` (Node 22) deterministically writes that single line to `$OUTPUT_DIR/entry.txt`
(default `/output`), validating first that it is one line of 1–200 characters and not
only whitespace. No network access, no randomness — the same bytes on every run.
